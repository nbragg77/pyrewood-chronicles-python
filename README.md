# The Pyrewood Chronicles

A text-based adventure game developed in Python as an academic
project for IT-140 in September 2021.

## About the Project

The original assignment called for a simple text-based game in
which the player navigated rooms, collected required items, and
reached a final encounter.

I completed the core project requirements early in the course and
used the remaining time to expand the application through
independent study and experimentation.

## Key Features

- Randomized item placement
- Randomized character attributes
- Object-oriented Player and Enemy classes
- Location-dependent enemy encounters
- Variable health and attack values
- Attribute-based skill checks
- Recruitable companions
- Environmental hazards and alternate paths
- Multiple victory conditions

## Technologies

- Python
- Object-Oriented Programming
- Data Structures
- Conditional Logic
- Randomization

## Running the Game

1. Download or clone this repository.
2. Open `pyrewood_chronicles.py` in a Python IDE or development environment.
3. Run the Python file.
4. The game will launch in the console/output window and display the available commands.
5. Enter commands when prompted to navigate the environment, collect items, recruit companions, and interact with encounters.

No additional packages or dependencies are required beyond Python.

### Basic Commands

- `north`, `south`, `east`, `west`, `up`, `down` — Move between locations
- `get [item]` — Add an available item to inventory
- `join [companion]` — Recruit an available companion
- `rest` — Recover health
- `q` or `quit` — Exit the game
